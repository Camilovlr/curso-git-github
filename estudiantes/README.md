# Estudiantes

Esta carpeta es donde cada estudiante deja su huella en el curso.

## Primer ejercicio práctico

1. Crea un archivo llamado `su-nombre.md` (reemplaza "su-nombre" por tu nombre, ej: `maria-lopez.md`).
2. Escribe en él una breve presentación: quién eres, qué esperas del curso.
3. Guarda (commit) el archivo con un mensaje claro, por ejemplo: `Agrega presentación de María López`.
4. Sube tus cambios y abre un Pull Request.

Con esto darás tu primer paso real usando Git y GitHub. 🙌
