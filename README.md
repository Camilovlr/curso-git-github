# Curso de Git y GitHub

Bienvenido/a. Este repositorio es el material práctico del curso: aquí vas a aprender Git y GitHub haciendo, no solo leyendo.

## ¿Qué vamos a hacer aquí?

A lo largo del curso vas a:
- Clonar este repositorio y trabajar sobre él.
- Crear tu propio archivo en la carpeta `estudiantes/` (tu primer commit).
- Colaborar con tus compañeros enriqueciendo los datos de la carpeta `datos/`.
- Practicar ramas (branches), pull requests y resolución de conflictos directamente sobre este repo.

## Cómo empezar

Tienes dos opciones:

**Opción A — Codespaces (recomendada, no instalas nada):**
1. Entra al repositorio en GitHub.
2. Click en **Code → Codespaces → Create codespace on main**.
3. Espera a que cargue el entorno (ya viene con Git instalado).

**Opción B — Clonar en tu computador:**
```bash
git clone https://github.com/jjsierramo/curso-git-github.git
cd curso-git-github
```

## Primer ejercicio

1. Ve a la carpeta `estudiantes/`.
2. Lee el `README.md` de esa carpeta.
3. Crea tu archivo `su-nombre.md`, súbelo con un commit y ábrelo como Pull Request.

Antes de empezar, lee `CONCEPTOS.md` para entender qué es Git, qué es GitHub y por qué existen.

¡Manos a la obra! 🚀
