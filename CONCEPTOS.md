# Conceptos clave: Git y GitHub

## 🔧 ¿Qué es Git?

Git es un **sistema de control de versiones**. Guarda el historial completo de los cambios en tus archivos, para que puedas volver atrás, comparar versiones o trabajar en paralelo sin pisar el trabajo de otros. Corre **localmente** en tu computador, no necesita internet.

## ☁️ ¿Qué es GitHub?

GitHub es una **plataforma web** que aloja repositorios de Git en la nube. Agrega funciones sociales y de colaboración: Pull Requests, Issues, revisiones de código, Actions (automatización), Codespaces, etc.

## 🆚 Diferencia entre Git y GitHub

| | Git | GitHub |
|---|---|---|
| Qué es | Herramienta / software | Servicio web |
| Dónde vive | Tu computador | La nube |
| Función principal | Versionar archivos | Alojar y colaborar en repos de Git |
| ¿Necesita internet? | No | Sí |

Git es el motor. GitHub es uno de varios lugares donde puedes estacionar ese motor (existen alternativas como GitLab o Bitbucket).

## 🐧 ¿Cómo surgió Git?

Git nació en 2005, creado por **Linus Torvalds**, el mismo creador del kernel de Linux. El equipo del kernel usaba una herramienta privativa (BitKeeper) para gestionar el código, y cuando perdieron el acceso a ella, Torvalds necesitó una alternativa **rápida, distribuida y gratuita** para coordinar a miles de colaboradores en todo el mundo. En apenas unas semanas escribió la primera versión de Git. Hoy es el estándar de facto en la industria.

## 💼 ¿Cómo se usa hoy?

- Es la base de casi todo el desarrollo de software profesional y open source.
- Se usa para versionar código, pero también documentos, configuraciones, infraestructura (IaC) e incluso este mismo curso.
- Empresas, universidades y proyectos open source lo usan para colaborar sin sobrescribirse el trabajo.

## ❓ ¿Por qué es importante?

- **Historial**: nunca pierdes una versión anterior de tu trabajo.
- **Colaboración**: varias personas pueden trabajar en lo mismo sin chocar.
- **Empleabilidad**: es una habilidad básica esperada en cualquier rol técnico.
- **Transparencia**: puedes ver quién cambió qué, cuándo y por qué.

En resumen: Git versiona, GitHub colabora. 🎯
